## 青序 · 日程小窗

青序是我写的一个 Windows 桌面日程小软件，本来是写给自己用的，想把 Excel 里的学习计划放到桌面上，随时看看接下来要做什么。可以翻看日程、拖拽安排任务，做完一件就打个勾。

现在把它放出来，也欢迎大家来试试。有什么用着不顺手的地方、想加的功能，或者碰到了 bug，都欢迎来提意见、一起 debug。现在还是预览版，运行前记得看看仓库里的说明。

[去看看青序 →](https://github.com/7Ambrose/qingxu)
